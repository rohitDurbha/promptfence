promptfence

A layered defense against prompt injection for tool-using LLM agents.

Every rule runs in your browser — nothing is sent anywhere, no model is called, and each verdict is reproducible. The rules are generated from the Python source, and a parity check in CI asserts both implementations return identical verdicts.

Examples

Measured on held-out public corpora: 33% of real injections blocked at 0% false positives (deepset/prompt-injections test split), and 53% on 1,000 in-the-wild Gandalf attempts. Regex is a first line, not a solution — the limits are documented in the repository.
